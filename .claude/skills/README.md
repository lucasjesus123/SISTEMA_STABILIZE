## harness-engineering-coding-agent

- **Origem:** https://github.com/AndreAlmeidaDC/harness-engineering-coding-agent
- **Autor:** André Almeida · **Licença:** MIT
- **Versão instalada:** 2026.06.24

Metodologia operacional para agentes de código: classificação da tarefa,
portões de qualidade, verificação e continuidade entre sessões.

As regras dela batem com as convenções já adotadas aqui — em especial
"nada de vitória prematura" (não marcar como pronto porque compilou ou
porque devolveu 200) e "nada de enfraquecer teste para passar". É a mesma
disciplina que fez o teste ponta a ponta desta API encontrar quatro bugs
reais no código recém-escrito.

O PDF do guia foi removido da cópia local por peso; está no repositório
de origem.

Atualização: a skill pede verificação de versão a montante antes de uso
relevante, e **exige consentimento do usuário** para atualizar. Não se
atualiza sozinha.
